# Записывалка вебинаров ВИШ

Отдельный сервис: заходит на онлайн-пару в вебинарной платформе ЧГУ
(BigBlueButton), снимает слайды и отдаёт их боту одним PDF. Бот рассылает
файл тем, у кого эта пара в расписании.

Живёт отдельно от бота, потому что ему нужен браузер (Chromium ≈ 400 МБ
оперативной памяти), а боту — нет.

## Как это работает

1. Раз в полминуты смотрим страницу вебинаров портала за сегодня.
2. За `LEAD_MINUTES` до начала нужной пары начинаем ждать кнопку «Подключиться»:
   портал показывает её только когда к вебинару уже можно зайти.
3. Как только кнопка появилась — просим у портала ссылку на комнату
   (`POST /webinar/getjoin`) и заходим туда headless-браузером.
4. Снимаем область презентации. Кадр сохраняется, только когда слайд реально
   сменился: сначала по номеру слайда, если он виден, иначе по хэшу картинки,
   и всегда после того, как картинка «устоялась» — так в пачку не попадают
   полурисованные кадры и дрожание от чужого курсора.
5. В конце пары собираем PDF и отправляем боту на `POST /slides`.

Бот в комнате виден как обычный участник — спрятать это нельзя и не нужно.
Имя задаётся в `WEBINAR_DISPLAY_NAME`. Если преподаватель против записи, он
просто удалит участника из комнаты.

## Настройка

```bash
cp .env.example .env     # заполнить
npm install
npx playwright install chromium --with-deps   # или взять образ с Chromium
npm run build
npm run probe            # разведка: пустит ли учётка и видно ли пары
npm start                # рабочий режим
```

### Разведка (`npm run probe`)

Печатает пары на сегодня и для каждой — можно ли к ней подключиться прямо
сейчас. Если можно, просит у портала ссылку на комнату; с аргументом `join`
(`npm run probe -- join`) ещё и заходит в комнату, кладёт в `data/slides/probe`
скриншот и слепок разметки. Слепок нужен, чтобы подобрать селектор области
презентации под конкретную версию BBB, если стандартные не подошли.

Разведку запускают **во время живого вебинара**: вне пары портал ссылку не даёт.

## Переменные окружения

| Переменная | Значение | Зачем |
|---|---|---|
| `WEBINAR_AUTH` | `0` слушатель, `1` обучающийся (по умолчанию), `2` сотрудник, `4` преподаватель | как портал проверяет вход в комнату |
| `WEBINAR_LOGIN` | почта/логин (для режима `0` — отображаемое имя) | учётка для входа |
| `WEBINAR_PASSWORD` | пароль | тоже |
| `WEBINAR_DISPLAY_NAME` | `Бот ВИШ (слайды)` | как бот подписан в списке участников |
| `FACULTY_ID` | `32` | факультет ВИШ |
| `RECORD_SUBJECTS` | пусто = все | записывать только эти предметы (через запятую, по части названия) |
| `RECORD_GROUPS` | пусто = все | записывать только пары этих групп |
| `LEAD_MINUTES` | `7` | за сколько минут до начала начинать ждать комнату |
| `POLL_SECONDS` | `30` | как часто опрашивать страницу вебинаров |
| `CAPTURE_SECONDS` | `5` | как часто смотреть на слайд |
| `MAX_MINUTES` | `110` | предохранитель: дольше этого в комнате не сидим |
| `BOT_SLIDES_URL` | `http://calendar.secretvish.ru:40070/slides` | куда отдавать PDF |
| `SLIDES_TOKEN` | длинная случайная строка | тот же токен прописан у бота |
| `OUT_DIR` | `./data/slides` | где складывать кадры и PDF |
| `HEADLESS` | `1` | `0` — показать браузер (для отладки на своей машине) |
| `CHROMIUM_PATH` | пусто | путь к Chromium, если playwright его не находит |

Секреты живут только в `.env` на сервере записи. В репозиторий они не
попадают: `.env` в `.gitignore`.

## Docker

```bash
docker build -t vish-recorder .
docker run --rm --env-file .env -v "$PWD/data:/app/data" vish-recorder
```

Образ собран на `mcr.microsoft.com/playwright`, Chromium там уже есть.
На Pterodactyl удобнее egg с поддержкой Docker-образа; в Node-egg браузер
придётся ставить отдельно (`npx playwright install chromium --with-deps`),
и контейнеру нужно ≥ 1.5 ГБ памяти.

## Чего он не делает

- Не пишет звук и видео — только слайды и то, что поверх них рисуют.
- Не обходит ограничения: если комната требует одобрения модератора, бот будет
  ждать в «приёмной», пока его не впустят, и уйдёт ни с чем.
- Не решает за преподавателя: материалы его, и спрашивать разрешение — это к
  людям, а не к коду.
