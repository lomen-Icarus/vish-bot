# Видео «Своё меню внизу в Бот ВИШ» (Remotion)

Вертикальный ролик 1080×1920, 30 fps, 35 с: как через настройки бота добавить в нижнее меню
«👥 Др. группы», «👨‍🏫 Где препод», «🎓 Поток» и получить меню 3 × 3. Сценарий — `PROMPT.md`.

Кадры в `public/frames` — точные копии экранов бота; тексты на них не перерисовываются.
Видео только анимирует их: зум камеры к месту нажатия, палец с волной касания, вспышка кнопки,
«поп» ➕→✅, перестройка меню в 3 × 3 и финальное «Готово!».

| Время | Сцена |
|---|---|
| 0:00–0:03 | Обложка, три новые кнопки пульсируют |
| 0:03–0:27 | Шаги 1–8 по 3 с: общий план → наезд → нажатие → общий план |
| 0:27–0:31 | Итог: меню собирается в 3 × 3, новые кнопки подсвечены |
| 0:31–0:35 | Чистый итог, зум к меню, «Готово!» |

Шапка чата и плашка шага при зуме неподвижны — текст шага всегда виден целиком.

## Запуск

```bash
npm i
npm run dev        # Remotion Studio: превью и правка таймингов
npx remotion render MenuTutorial out/vish-menu-tutorial.mp4
```

Настройки вывода (`remotion.config.ts`): H.264, yuv420p, BT.709, CRF 18 — подходит для
Reels / Shorts / Telegram. Шрифт Inter лежит в `public/fonts` (OFL), рендер не ходит в сеть.

## Где что править

- `src/data.ts` — точки нажатия, рамки кнопок, высота плашек, сила зума по шагам.
- `src/scenes/TapStepScene.tsx` — тайминг шага (наезд, нажатие, возврат).
- `src/MenuTutorial.tsx` — порядок сцен и переходы (10 кадров ≈ 0.33 с).
