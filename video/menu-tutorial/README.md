# Видео «Своё меню внизу в Бот ВИШ» (Remotion)

Вертикальный ролик 1080×1920, 30 fps, ≈29 с: как через настройки бота добавить в нижнее меню
«👥 Др. группы», «👨‍🏫 Где препод», «🎓 Поток» и получить меню 3 × 3. Сценарий — `PROMPT.md`.

Кадры — экраны бота. Видео анимирует их: при подлёте пальца кнопка обводится розовой рамкой
целиком, палец нажимает, кнопка вспыхивает, ✅ «подпрыгивает», меню собирается в 3 × 3,
в конце — «Готово!». Камера на шагах не двигается; бот «отвечает» через ~0.13 с после
нажатия (новый экран полностью виден через ~0.47 с).

## Кадры: `source/frames` → `public/frames`

Исходные кадры лежат в `source/frames`, в ролик идут подготовленные `public/frames`:

```bash
python3 tools/prepare_frames.py   # numpy, Pillow, шрифт Inter (INTER_DIR)
```

Что делает скрипт:
- снимает запечённые розовые рамки и круги с 01–08 (рамку теперь рисует видео). Обои Telegram
  привязаны к экрану, поэтому чистые пиксели берутся с кадра, где в тех же координатах та же
  кнопка без метки; для 02 — перенос с кадра 03 с поправкой на узор обоев (`tools/remove_markers.py`);
- картинка дня на 01/02 — «Воскресенье, 8 ноября, ВИШ-67-67», нарисована кодом бота:
  `npx tsx video/menu-tutorial/tools/render-card.mts video/menu-tutorial/source/card-sunday-vish-67-67.png`
  (из корня репозитория); кнопки под ней — «◀ 07.11» и «09.11 ▶»;
- на кадре настроек — «👥 Группа: ВИШ-67-67»;
- в поле ввода на 01–10 — «67-67, Иванова, матан, 15.10».

Новые надписи — тем же шрифтом (Inter), фон под ними восстановлен по обоям.

| Время | Сцена |
|---|---|
| 0:00–0:03 | Обложка, три новые кнопки пульсируют |
| 0:03–0:21 | Шаги 1–8 (шаг 1 — 3.2 с, остальные по 2.5 с): палец + рамка → нажатие → сразу ответ бота |
| 0:21–0:25 | Итог: меню собирается в 3 × 3, новые кнопки подсвечены |
| 0:25–0:29 | Чистый итог, медленный зум к меню, «Готово!» |

## Запуск

```bash
npm i
npm run dev        # Remotion Studio: превью и правка таймингов
npx remotion render MenuTutorial out/vish-menu-tutorial.mp4
```

Настройки вывода (`remotion.config.ts`): H.264, yuv420p, BT.709, CRF 18 — подходит для
Reels / Shorts / Telegram. Шрифт Inter лежит в `public/fonts` (OFL), рендер не ходит в сеть.

## Где что править

- `src/data.ts` — точки нажатия, границы кнопок (по ним рисуется рамка), высота плашек, длина шагов.
- `src/scenes/TapStepScene.tsx` — задержка ответа бота после нажатия (`RESPONSE_DELAY`).
- `src/MenuTutorial.tsx` — порядок сцен и переходы (10 кадров ≈ 0.33 с).
