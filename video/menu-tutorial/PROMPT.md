# Промпт для видео-ИИ: «Своё меню внизу в Бот ВИШ» (9:16)

К промпту приложены 11 кадров 1080×1920 (`png/00_cover.png` … `png/10_final_clean.png`).
Это точные копии экранов бота: подписи кнопок и тексты сняты из кода бота, а не придуманы.
**Лучший режим — image-to-video / keyframes:** каждый кадр — ключевой, ИИ только анимирует переходы,
палец и подсветку. Если сервис умеет только text-to-video — кадры прикладываются как референсы.

## 1. Короткий промпт (вставить в поле prompt)

**RU:**
> Вертикальное видео 9:16, 1080×1920, ~35 секунд, обучающий скринкаст мессенджера Telegram на смартфоне (светлая тема).
> Чат с ботом «Бот ВИШ» (аватар — голубой мультяшный робот с жёлтыми глазами и логотипом ВИШ). Фон чата — зелёно-жёлтый
> градиент с лёгким узором. Внизу экрана — нижнее меню из светло-серых кнопок, над ним поле ввода «14-24, Иванова, матан, 15.10»

> нажимает нужную кнопку, кнопка коротко подсвечивается, экран меняется. Сверху — тёмная плашка с номером шага.
> Используй приложенные кадры как ключевые: НЕ меняй тексты, порядок и подписи кнопок, эмодзи и раскладку.
> Стиль: чистый, спокойный, без лишних эффектов; темп — 3 секунды на шаг; переходы — мягкие (0.3–0.4 с).
> Финал: новое меню 3 × 3 с подсветкой трёх новых кнопок и надпись «Готово!».

**EN (если сервис лучше понимает английский):**
> Vertical 9:16 video, 1080×1920, ~35 s, a tutorial screencast of the Telegram messenger on a smartphone (light theme).
> A chat with a bot named «Бот ВИШ» (avatar: a cute light-blue cartoon robot with big yellow eyes and a ВИШ logo).

> through the bot's settings, turning the 2×3 menu into 3×3. On every step: smooth camera push-in (1.15–1.3×) to the
> action area, a semi-transparent fingertip / tap circle with a pink outline presses the target button, the button

## 2. Как выглядит бот (контекст для ИИ)

- **Приложение:** Telegram на телефоне, светлая тема.
- **Шапка чата:** круглый аватар, имя **«Бот ВИШ»**, ниже серым «бот». Под шапкой — плашка
  «Закреплённое сообщение / Фотография» с синей полосой слева и крестиком справа.
- **Фон чата:** зелёно-жёлтый градиент с узором Telegram.
- **Сообщения бота:** белые пузыри слева. Под ними — **кнопки под сообщением** (inline): полупрозрачные
  тёмно-зелёные плашки с белым жирным текстом, по 1–2 в ряд.
- **Сообщения пользователя:** светло-зелёные пузыри справа с двумя галочками.
- **Нижнее меню** (reply-клавиатура): светло-серые кнопки с тёмным текстом, по 3 в ряд, над ним поле ввода
  с подсказкой «14-24, Иванова, матан, 15.10», слева синяя кнопка «Меню», справа значок ▦.
- **Важно про поведение:** кнопки «⚙️ Настройки», «⌨️ Нижнее меню», «🧩 Кнопки внизу» и все ➕/✅
  **меняют то же сообщение на месте** (новые сообщения в чат не приходят). Новое сообщение появляется только
  после «🗂 Ещё», «⚙️ Настройки» в панели «Ещё» и «👌 Готово». Нижнее меню меняется **только на последнем шаге**.

**Было (меню по умолчанию, 2 × 3):**
```
📅 Сегодня   | 📅 Завтра      | 🗓 Неделя
🔍 Найти с ИИ | 🗂 Ещё         | 🙋 Поддержка
```
**Стало (цель, 3 × 3):**
```
📅 Сегодня   | 📅 Завтра      | 🗓 Неделя
🔍 Найти с ИИ | 👥 Др. группы  | 👨‍🏫 Где препод
🎓 Поток     | 🗂 Ещё         | 🙋 Поддержка
```
Порядок бот расставляет сам — пользователю двигать кнопки не нужно.

## 4. Тексты на экране (точно, без изменений)

- Плашки шагов: см. колонку «Плашка сверху».
- Ответы-подсказки бота (короткая всплывашка после нажатия):
  - «Добавил: 👥 Др. группы. Нажми «Готово», чтобы обновить меню.»
  - «Добавил: 👨‍🏫 Где препод. Нажми «Готово», чтобы обновить меню.»
  - «Добавил: 🎓 Поток. Нажми «Готово», чтобы обновить меню.»
- Итоговое сообщение бота: «Готово: меню внизу 👇 Вернуть как было — ⚙️ Настройки → ⌨️ Нижнее меню → 🧩 Кнопки внизу → ↩️ Как было.»

## 5. Озвучка / субтитры (по желанию)

1. «Хочешь, чтобы нужные кнопки были всегда под рукой? Собери своё меню.»
2. «Жми «Ещё» внизу.»
3. «Открой «Настройки».»
4. «Раздел «Нижнее меню».»
5. «Дальше — «Кнопки внизу».»
6. «Плюсик — добавить кнопку. Добавим «Др. группы», «Где препод» и «Поток».»
7. «Жми «Готово» — новое меню придёт сразу.»
8. «Готово! Вернуть как было — там же, кнопкой «Как было».»

## 6. Технические параметры

- 1080×1920, 30 fps, H.264, ~35 с; безопасные поля 64 px сверху/снизу (под интерфейс Reels/Shorts/Stories).
- Музыка — спокойный лоу-фай без слов, громкость под голос.
- Если сервис портит кириллицу: генерировать только движение между готовыми кадрами (image-to-video, «keep text static»),
  а плашки шагов и субтитры наложить потом в монтаже (CapCut и т. п.).
