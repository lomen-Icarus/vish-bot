# Discovery: бот расписания ЧувГУ (ВИШ)

Дата: 2026-09-13. Статус: исследование до старта разработки.
Секретов в этом файле нет и быть не должно: токены и пароли живут только в переменных окружения сервера.

## 1. Источник данных: tt.chuvsu.ru

Официального API нет. Сайт — классическое серверное PHP-приложение с формами и cookie-сессией.
Всё ниже подтверждено по исходникам библиотеки `chuvsu-js` v5.2.1 (npm, MIT, обновлена 2026-09-12,
автор artegoser, 42 проверенные вручную HTML-фикстуры реальных страниц, 1184 пары).

### Авторизация

| Действие | Запрос | Поля формы |
|---|---|---|
| Гостевой вход | `POST /auth` | `guest=Войти гостем`, `hfac=0`, `pertt=<период>` |
| Вход по учётке | `POST /auth` | `wname=<email>`, `wpass=<пароль>`, `wauto=1`, `auth=Войти`, `hfac=0`, `pertt` |

Успех = HTTP 302 и cookie сессии. Признак протухшей сессии: в ответе есть `name="wname"` (форма логина).
**Вывод: для расписания учётка пользователя не нужна, гостевой вход даёт те же данные.**

### Эндпоинты расписания

| Что | Запрос | Разбор |
|---|---|---|
| Список факультетов | `GET /` | кнопки `.facbut`, id из `onClick="...val(<id>)"` |
| Группы факультета | `POST /` с `hfac=<facId>`, `pertt` | кнопки `button[id^='gr']`, `value` = имя группы, id из `val(<id>)` |
| Поиск группы | `POST /` с `grname=<строка>`, `findgr=найти`, `hfac=0` | те же кнопки |
| Расписание группы | `POST /index/grouptt/gr/<groupId>` с `htype=<период>` | таблица (см. ниже) |
| Расписание преподавателя | `POST /index/techtt/tech/<id>` с `htype` | таблица |
| Расписание аудитории | `POST /index/audtt/aud/<id>` с `htype` | таблица |
| Вебинары на дату | `POST /webinar` с `seldate=YYYY-MM-DD`, `selfac`, `pertt` | список |

Период (`pertt` / `htype`): 1 = осенний семестр, 2 = зимняя сессия, 3 = весенний семестр, 4 = летняя сессия.
Учебный год берётся со страницы по шаблону `2026/2027 учебный год`.

### Структура HTML расписания группы (семестр)

- Строка дня: `tr.trfd` со `style` содержащим `lightgray`, первая `td` = название дня.
- Строка пары: `td.trf > .trfd` содержит `N пара (HH:MM - HH:MM)`; данные в `td.trdata` во вложенной `table tr`.
- Предмет: `span[style*="color: blue"]`. Тип пары в скобках: `лк|пр|лб|зачо|зач|экз|конс|кп|из|гз|крп`.
- Аудитория: текст перед предметом в той же строке. `ДОТ`/`дистанционно` = дистанционная пара.
- Недели: `(N-M нед.)`. Чётность: `<sup>*</sup>` = нечётная, `<sup>**</sup>` = чётная неделя.
- Подгруппа: `(N подгруппа)`. Преподаватель: строка после предмета (`доц.`, `к.т.н.` и т. п. отрезаются).
- Замены/переносы: `div[style*="border: 2px solid red"]` с текстом
  `DD.MM.YYYY замена на:` (Аудитория:/Преподаватель:), `DD.MM.YYYY замена вместо:`,
  `DD.MM.YYYY перенос с DD.MM.YYYY (N пара)`.
- Ячейка с классом `want` = «возможны изменения».
- `День самостоятельной работы` = отдельный маркер дня.
- Сессия: ячейки `td[id^="trd2"]` вида `trd20251224` (дата в id), время после `<br>`.

### Особенности

- TLS-цепочка сайта неполная: `chuvsu-js` вшивает промежуточные сертификаты GlobalSign. На сервере нужен такой же доверенный набор.
- Семестр: осень с 1 сентября, весна с первого понедельника февраля, 17 недель.
- `chuvsu-js` даёт **стабильные ID пар** (серия + конкретное занятие), не зависящие от даты/аудитории/времени, и хранит их в подключаемом репозитории (compare-and-set). Это готовая основа для детекции изменений.
- Личный кабинет `lk.chuvsu.ru` (`/info/login.php`, `/student/personal_data.php`, `/student/tt.php`) тоже покрыт библиотекой, но для расписания не нужен.

## 2. Хостинг: panel.frienworld.space

FrienWorld — российский игровой хостинг на панели **Pterodactyl** (URL `/server/<8 hex>` — её клиентская часть).
Следствия:
- деплой = загрузка файлов через панель/SFTP или через Client API (`Account → API Credentials`), плюс рестарт;
- готовые GitHub Actions: `rexlManu/pterodactyl-upload-action`, power-action для рестарта;
- «egg» сервера определяет рантайм (Node.js / Python / Docker generic). Нужно уточнить, какой стоит.

## 4. Предлагаемый стек (обсуждается)

- **Runtime**: Node.js 22 LTS, TypeScript, ESM.
- **Telegram**: grammY 1.46 + плагины `conversations`, `menu`, `runner`.
- **Портал**: `chuvsu-js` 5.2.1 (парсер, стабильные ID, кеш, справочники).
- **БД**: SQLite (better-sqlite3 13) + drizzle-orm 0.45; файл БД в папке сервера, бэкап = копия файла.
- **Планировщик**: croner 10 (поллинг каждые 15 минут с джиттером, напоминания по расписанию).
- **Рендер карточек**: satori + @resvg/resvg-js (PNG из JSX без браузера).
- **Логи/наблюдаемость**: pino, health-endpoint, алерты владельцу в Telegram.
- **LLM (опционально)**: `@anthropic-ai/sdk`, модель `claude-opus-5`, структурированный вывод; сценарии: вопросы на естественном языке, фолбэк при поломке парсера.
- **CI/CD**: GitHub Actions → сборка → загрузка в Pterodactyl → рестарт.
