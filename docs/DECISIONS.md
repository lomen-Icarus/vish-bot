# Решения (ADR-лайт)

Зафиксировано по ответам заказчика 2026-09-13.

| # | Тема | Решение |
|---|---|---|
| 1 | Источник | `tt.chuvsu.ru`, гостевой вход. Личный кабинет не нужен, учётка студента не используется. |
| 2 | Аудитория | Только ВИШ (факультет 32). Заочные `ОЗВИШ-*` скрыты и не опрашиваются (`HIDDEN_GROUP_PREFIXES`). |
| 3 | Объединение групп | Одинаковые номер и год = одна группа: `ВИШ-12-23` + `ВИШ-12-23иот (…)`, `ВИШ-13-23` + `ВИШ-13-23иот`. Разные квалификаторы без «иот» остаются разными: `ВИШ-11-23 (ЭиЭА)` ≠ `ВИШ-11-23(РЗиАЭС)`. Следы «иот» пользователю не показываются, расписание = объединение вариантов. |
| 4 | Опрос | Каждые 6 минут в 07:00–21:00 пн–сб, каждые 30 минут в остальное время (cron в `.env`). Между запросами к порталу 0.9 с. У портала нет API, только HTML. |
| 5 | Что считать изменением | Диф по конкретным датам: добавлена, убрана, перенесена, сменилась аудитория/время/формат. Уведомляем о датах от сегодня до +14 дней; в `/changes` видна история. |
| 6 | Напоминания | Пользователь выбирает сам: до первой пары (30 мин–3 ч), перед каждой парой, отдельно перед дистанционной парой (5/10/15 мин) со ссылкой на `tt.chuvsu.ru/webinar`, вечером на завтра, тихие часы. «Рекомендуемые в один клик» = изменения + за 2 часа до первой пары + за 5 минут до дистанта. |
| 7 | Подгруппы | Опциональный фильтр в настройках; по умолчанию показываем обе подгруппы. |
| 8 | Формат | Текст, картинка-постер или оба (по умолчанию оба). Постеры рисует satori + resvg без браузера. |
| 9 | Сессия | Расписание сессии подгружается, изменения по нему приходят только тем, кто включил «Сессия» в настройках. |
| 10 | Новости и объявления | Три темы: «Конкурсы и стипендии», «Объявления», «События ВИШ». Источники: ручная рассылка админа (с подтверждением), канал по хэштегам, ежедневный ИИ-сканер источников (`/sources`). Красный баннер портала уходит только админам и в «Изменениях» не показывается. |
| 11 | Медиа-ВИШ | Кнопка «Предложить новость»: сообщение пересылается в чаты из `MEDIA_CHAT_IDS`. |
| 12 | ИИ | Модель `claude-sonnet-5` везде. `/ask` работает через tool runner: инструменты «расписание любой группы», «найти предмет по разговорному названию», «список групп»; кнопка «Ответ неверный» шлёт вопрос-ответ админу. Лимиты: 10 вопросов/день на человека, 300/день всего. Включается наличием `ANTHROPIC_API_KEY`. |
| 13 | Админ | Telegram ID `5985343016` (список в `ADMIN_IDS`). Команды `/admin`, `/stats`, `/health`, `/poll`, `/broadcast`. |
| 14 | Тон | На «ты», сдержанно. |
| 15 | Стек | Node.js 22, TypeScript, grammY, chuvsu-js, SQLite через встроенный node:sqlite, croner. MariaDB хостинга не используется. |
| 16 | Хостинг | Pterodactyl (FrienWorld), egg Node.js, long polling. HTTPS не нужен. Автодеплой из GitHub Actions через Client API. |
| 17 | Секреты | Только в `.env` на сервере и в GitHub Secrets. В репозитории и переписке не хранятся; скомпрометированные токены заменить. |
| 18 | Inline-режим | `@бот 12-23 завтра` в любом чате вставляет расписание дня. |
| 19 | Преподаватели | Портал показывает расписание преподавателей только авторизованным. Раздел работает при заданных `PORTAL_LOGIN`/`PORTAL_PASSWORD` (отдельный клиент с учёткой), справочник кешируется на сутки. Поиск нечёткий: фамилия и имя в любом порядке, инициалы, префиксы; если локально пусто — поиск на портале. Последняя ошибка портала видна в `/health`. |
| 20 | Поток | Режим «Поток»: все группы одного набора (23/24/25/26) одним экраном, одинаковые пары объединяются, «Общие пары» = лекции, где своя группа сидит с другими. |
| 21 | Источник новостей | Каналы/чаты из `NEWS_CHANNEL_IDS` (бот там админ). Пост с хэштегом `#конкурс`, `#объявление`, `#событие` (и синонимами) уходит подписчикам темы, `#всем` — всем. Без хэштега пост игнорируется. Плюс ручная рассылка админа. |
| 22 | Клавиатура | 12 кнопок: Сегодня, Завтра, Др. группы / Неделя, Следующая, Поток / Изменения, Календарь, Преподаватели / Функции, Поиск, Настройки. «Отправить новость» осталась командой `/suggest` (без `MEDIA_CHAT_IDS` уходит админам). |
| 23 | ИИ-сканер новостей | Раз в день (`NEWS_SCAN_CRON`, 10:30 МСК) бот читает источники из `/sources`: превью публичных Telegram-каналов (`t.me/s/…`), стены VK (нужен `VK_SERVICE_TOKEN`), ленту Tilda сайта ВИШ. Посты за `NEWS_LOOKBACK_HOURS` (32 ч) Sonnet 5 раскладывает по темам, подходящие уходят подписчикам с кнопкой «Не по теме» (жалоба уходит админам). Не более `NEWS_MAX_PER_TOPIC` (8) постов на тему за скан. |
| 24 | Календарь | Два режима. Подписка: личная ссылка `PUBLIC_URL/cal/<token>.ics` (HTTP-сервер бота на порту `SERVER_PORT`), календарь телефона обновляет её сам, дубликатов нет. Файл .ics: пары до конца семестра, будильник за 15/30/60 мин; UID пары стабилен, `SEQUENCE` растёт с каждой генерацией, убранные/перенесённые пары идут как `STATUS:CANCELLED`. Под «Изменениями» и в уведомлении об изменениях — файл «только изменения». Будильник телефона напрямую включить нельзя: ближайшее — напоминание в событии календаря. |
| 25 | Рассылка | Перед отправкой показывается аудитория и число получателей, нужен явный «Отправить»; кнопка «Отмена» на каждом шаге. |
| 26 | Доска объявлений | Рассылка «Всем» или в тему «Объявления» попадает на доску в «Изменениях» на 24 часа (несколько сразу); админ может убрать раньше кнопкой под отчётом о рассылке или через `/announcements`. |
| 27 | Актуальность изменений | В «Изменениях» показываются только события с датой ≥ сегодня, созданные за последние 14 дней; прошедшие исчезают сами. |
| 28 | Слежение за группами | Кнопка «Убрать все слежения» в настройках; в уведомлении по чужой группе — «Не следить за группой». Уведомления по своей группе получают кнопку «Обновить в календаре». |
| 29 | Постеры | Стрелки обновляют картинку на месте (`editMessageMedia`), а не шлют новую. Чётность недели — отдельная плашка в шапке. Тема оформления выбирается `POSTER_THEME` (midnight по умолчанию; варианты editorial, brutalist, timeline). |
| 30 | Эмодзи | Без ярко-красных «тревожных» эмодзи (🚫 🆘 ❌ ⛔ 🛑); мягкие красные оттенки допустимы. |
| 31 | Поиск и ИИ | Кнопка «Поиск» ищет группы, предметы (своя группа, затем все) и преподавателей. `/ask` отвечает и про преподавателей инструментом `find_teacher` (предметы, группы, ближайшие пары из расписания); биографию бот не знает. |

## Открытые вопросы

- Mini App (веб-интерфейс недели) требует HTTPS-домена; на хостинге есть слот «proxies: 1», нужно проверить, даёт ли он домен с SSL для порта 40070.
- Образ Node 18 в egg'е: попросить FrienWorld добавить `nodejs_22`; до этого работает лаунчер с портативным Node.
