## Открытые вопросы

- Mini App (веб-интерфейс недели) требует HTTPS-домена; на хостинге есть слот «proxies: 1», нужно проверить, даёт ли он домен с SSL для порта 40070.
- Образ Node 18 в egg'е: попросить FrienWorld добавить `nodejs_22`; до этого работает лаунчер с портативным Node.
- Перенос выходных по производственному календарю (1 и 9 мая на выходные и т. п.) бот не знает: праздники — фиксированные даты. Нужен список нерабочих дней на год.
- Альбом из канала с хэштегом уходит подписчикам одной фотографией (с подписью): остальные фото альбома приходят без хэштега.
- Одна «ядовитая» новость (отказ модели, нечитаемый ответ) валит свою пачку из 30 при каждом скане; соседи догоняются, пока не выйдут 72 часа.
