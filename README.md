# vish-bot

Telegram-бот расписания Высшей инженерной школы ЧувГУ. Берёт данные с портала `tt.chuvsu.ru` (гостевой доступ), объединяет «физические» группы портала в логические, замечает изменения и присылает их подписчикам, напоминает о парах, рисует расписание постером.

## Возможности

- 📅 день / завтра / неделя / любая дата / другие группы, навигация стрелками, постер обновляется на месте;
- 🔔 уведомления об изменениях в расписании своей группы (переносы, замены аудиторий, отмены, новые пары) и, по желанию, других групп (с кнопкой «Не следить»). Всё, что изменилось за раз, приходит **одним сообщением**: сверху срочное **на сегодня** — весь день, где затронутые пары помечены (✏️ изменилась, ➕ новая, ↪️ перенесена, ❌ отменена), следом **на будущее** — списком по дням с пометкой недели. Текстом — одно сообщение с кнопками; картинкой — постер с подписью, а если задето несколько дней — альбом постеров с подписью (у альбома кнопок нет, поэтому «📆 Файл изменений в календарь» в подписи — ссылкой). Кнопка «🔔 Изменения» с настройкой «картинка» тоже присылает постеры дней. Подозрительно большая пачка изменений (сбой портала) не рассылается, пока админ не нажмёт «Разослать»;
- 🎓 отдельная подписка на расписание сессии;
- ⏰ напоминания: до первой пары, перед каждой парой, за 5 минут до дистанта со ссылкой на вебинар, вечером «на завтра», тихие часы;
- 📌 доска объявлений на 24 часа (из рассылок администратора) прямо в «Изменениях»; рассылки по всем, по курсу или по теме;
- 📆 календарь телефона: подписка по ссылке (обновляется сама, ничего не дублируется) или файл .ics; отдельный файл «только изменения»;
- 📨 «предложить новость» медиа-ВИШ (`/suggest`);
- 💬 `/ask` — вопросы о расписании и преподавателях своими словами (Claude Sonnet 5 с инструментами, включается ключом, с дневными лимитами);
- 📰 ИИ-сканер новостей: Telegram-каналы, VK, сайт ВИШ → темы подписок, жалоба «не по теме»;
- 👨‍🏫 преподаватели: онлайн-пары (кто ведёт и тема) видны всегда, полное расписание преподавателя — с учёткой портала; 🎓 режим потока с мини-кнопками групп, 🔍 поиск по группам, предметам и преподавателям;
- ⌨️ нижнее меню сворачивается значком ▦ в поле ввода (и на телефоне тоже); в ⚙️ Настройках «Нижнее меню» можно сделать, чтобы оно сворачивалось само после каждого нажатия, или скрыть его совсем — тогда всё в кнопке «Меню» слева от поля ввода, вернуть кнопки — `/menu`;
- 🖼 постеры с выделенной чётной/нечётной неделей, несколько тем оформления (`POSTER_THEME`);
- 🕵️ глобальный поиск студента (`POISK=TRUE`): по ФИО находит группу человека и показывает, где он должен быть сейчас по расписанию, плюс его день с обычными кнопками. Реестр людей лежит только на сервере (`POISK_DB`) и в репозиторий не попадает;
- 🤖 лимиты вопросов к ИИ меняются из админки на ходу, включая разовый «буст» на сегодня;
- 👨‍🏫 карта преподавателей: пометка «(ВИШ)» у тех, кто ведёт у школы (тёзки в университете не редкость), фото преподавателя и кнопка «следить» — его расписание придёт вечером и за 2 часа до первой пары;
- 📎 запись вебинаров: отдельный сервис `recorder/` заходит на онлайн-пару, снимает слайды и присылает их боту одним PDF, а бот раздаёт файл группе;
- 👤 единая карточка человека: преподаватель и студент (при `POISK=TRUE`) выглядят одинаково, откуда бы их ни нашли — кнопкой, поиском, ИИ или inline: кто это, где он сейчас по расписанию, пары дня и одинаковые кнопки;
- inline-режим: `@бот 12-23 завтра`, `@бот неделя`, `@бот поток 24`, `@бот общие`, `@бот Беляев завтра` (расписание человека) — в любом чате (нужно один раз включить в @BotFather: `/setinline`);
- 👨‍🏫 режим преподавателя (`/prepod`, реестр `TEACHERS_DB` только на сервере): преподаватель видит свои пары как «свою группу», третья кнопка — «👥 Студенты»;
- 📚 `/subjects` (тестово): предметы семестра и таблица пар по каждому — сколько и когда ЛК, ПР, ЛБ, что прошло и что осталось;
- 💬 болталка в группах: «@бот привет» — ответ через Claude с учётом разговора, про пары и преподавателей — по расписанию, сценарий «вопрос;ответ» от админа (CSV), дневные лимиты и включение чатов в админке (`/chats`). Настройка — `docs/DEPLOY.md`, раздел «раунд 8».
- 🤝 «социальность» в группах: бот спрашивает «а что это за группа?» и запоминает ответ, подписывает тему чата на слайды вебинаров («@бот сюда слайды по физике»), сверяет время собрания с парами, знакомится («@ник это Фамилия Имя 12-23») и зовёт знакомых по имени, записывает идеи для бота, ночью сонно ворчит.

## Как это работает

```
tt.chuvsu.ru ──(guest, каждые 6 мин в учебное время)──► PortalClient ──► chuvsu-js parsers
                                                                             │
      логические группы (ВИШ-12-23 = ВИШ-12-23 + ВИШ-12-23иот …) ◄── merge ◄─┘
                                                                             │
      «идет N ** неделя» на странице ──► калибровка недели 1 ──► expand ──► даты
                                                                             │
                     SQLite baseline ◄──── diff ────► события ────► Telegram-уведомления
```

Подробности исследования портала: `docs/research/2026-09-13-discovery.md`. Деплой: `docs/DEPLOY.md`.

## Разработка

```bash
npm install
cp .env.example .env            # заполнить BOT_TOKEN
npm run typecheck && npm test
npm run poll:once               # опросить портал без Telegram
npx tsx src/cli.ts day 12-23    # напечатать день
npx tsx src/cli.ts render 12-23 # PNG в ./out
npm run dev                     # бот с автоперезапуском
```

В песочнице за перехватывающим прокси портал доступен только с `PORTAL_TLS_INSECURE=1` (никогда не включать в продакшене: там используется вшитая цепочка GlobalSign).

## Стек

Node.js 22, TypeScript, grammY, chuvsu-js (парсеры портала), встроенный node:sqlite (без нативных модулей), croner, satori + resvg (постеры), pino, zod, `@anthropic-ai/sdk` (опционально).
